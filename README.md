### 🏭 Predictive Maintenance Dashboard
*End-to-end · Industrial internship project*

Shows the maintenance team **which component is likely to fail next** and **how many faults to expect next week**, so unplanned downtime becomes plannable.

- ML model for at-risk components + **time-series forecast** of fault volume
- Trained on **1+ year of production data**, guarded against data leakage
- Full pipeline: **database → model → live dashboard**
- **MLOps** with automated weekly retraining

### 🛠️ Assembly Planning App
*End-to-end · Sole developer · Industrial internship project*

Replaced an error-prone **Excel/VBA system** for assembly planning and commissioning: the full quoting process from configuration to **PDF quote for 105 countries**.

- Calculation logic for **4 machine types** rebuilt via reverse engineering
- **3-tier architecture**: Streamlit · FastAPI · PostgreSQL
- Roles, snapshot versioning, self-service master data
- Deployed on an **Ubuntu VM**
